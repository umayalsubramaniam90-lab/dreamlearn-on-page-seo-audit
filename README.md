## Overview

DreamLearn is an online learning website focused on creative and digital skills (Graphic Design, Web Design, UI/UX Design, VFX & Motion Graphics and Digital Marketing). This project is an on-page SEO audit and optimization of five pages of the site, carried out with Yoast SEO and documented in a detailed report and a structured audit spreadsheet.

## Work Covered

- Yoast SEO installation and configuration
- Keyword research using Google autocomplete
- Focus keyphrase selection for all five pages
- SEO title and meta description optimization
- URL structure, heading structure and image ALT text review
- Internal and external linking review
- Content quality assessment
- Findings and future recommendations

## Key Findings

- The site has clear navigation, descriptive URLs and relevant course categories.
- The Courses page "Learn More" buttons do not yet link to dedicated course pages.
- The Blog page shows article cards, but individual blog posts have not been created.
- No external links were added artificially.

## Scope Note

This project covers on-page SEO only. It does not include ranking, traffic, click, backlink or conversion data, and it makes no claim of improved search performance.
